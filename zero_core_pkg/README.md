## 📜 1分でわかる「非破壊プル（Parchment Pull）」構造
他者が自作した既存エンジンやEEG監視システムが存在していても、衝突（Conflict）を起こさずに安全にコード・データを取り込み（Pull）、歯車を噛み合わせます。

```text
[ 他者の自作システム / 既存EEGデーモン ] 
          │
          ├── (1) 既存のプロセスは完全無傷で継続
          └── (2) Parchment Pull (羊皮紙引き込み) ──► [ zero_core / hook.py ]
                                                               │
                                         ┌─────────────────────┴─────────────────────┐
                                         ▼                                           ▼
                              [ 🔐 E2EE 密談・ビジネスチャット ]           [ 💰 P2P 自動契約・エスクロー ]

⚙️ 独自プル概念: Parchment Pull & Gear Engage
当リポジトリへの貢献（Pull Request）は、コードの書き換えではなく**「機能の幾何学フック（差し込み）」**として処理されます。
 * Parchment Pull (プル引き込み):
   zero_core.hook.safe_init() を経由することで、相手の動作環境を汚さずにパケット構造体（DAG）のみを引き込みます。
 * Gear Engage (マージ/同調):
   メモリ常駐型のバイナリ流し込み（RAM Only）を行い、ストレージに証拠を残さず同調完了します。
